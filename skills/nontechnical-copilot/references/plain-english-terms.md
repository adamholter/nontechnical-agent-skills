# Technical terms in plain English

Use these explanations only when the term matters. Do not turn the answer into a glossary.

- **Localhost:** The app is running only on this computer. It is a private preview, not a public website.
- **Server:** A program or computer that provides an app or website when something asks for it.
- **Terminal:** A text-based way to ask the computer to do something. The agent should run commands itself when tools allow it.
- **Git:** A tool that keeps a history of changes to a group of files. A commit is a named checkpoint.
- **GitHub:** A website that stores Git projects online. Publishing code there does not automatically publish a working website.
- **Repository:** The project folder and its saved change history. People often shorten this to "repo."
- **Branch:** A separate line of changes that does not alter the main version right away.
- **Dependency:** Another piece of software the project needs.
- **Environment value:** An app setting stored outside its normal files. Some contain secrets and must stay private.
- **Deployment:** A released copy of an app or website that other people can reach.
- **Domain:** A readable web address such as `example.com`.
- **API:** A defined way for two programs to exchange requests and results.
- **Authentication:** Proving which account is being used, often by signing in or approving access.
