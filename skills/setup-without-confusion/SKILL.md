# Setup without confusion

Own the setup from the user's requested outcome through a verified result.

## Workflow

1. Define the finished state in one plain sentence.
2. Inspect the machine, project, existing accounts, and current setup before changing anything.
3. Choose the shortest reliable route. Install or configure required tools when that work is in scope.
4. Continue through normal prompts, sign-in pages, and confirmations. Do not stop at an intermediate screen.
5. Preserve existing work and avoid exposing passwords, access keys, private files, or personal data.
6. Verify the exact user-facing result. Open the page, run the app, test the connection, or read back the published item as appropriate.
7. Give a short handoff. State what works and any single action the user still needs to take.

## Communication rules

- Do not make the user choose between technical methods when the agent can choose safely.
- Do not paste commands or error dumps as the explanation.
- Translate an error into what it means and what the agent is doing next.
- If the user must copy text, isolate the exact text and nothing else.
- If a wait is unavoidable, say what is happening and keep working when possible.
